# 全局适用范围（必须先理解）

`03_FINAL_VISUAL_TARGET.jpeg` 是**视觉质量与融合关系的示范**，不是只需要复刻的单一画面，也不是只针对某一个瞬间。

以下要求属于项目级 Design/Interaction System，必须应用到所有采用视频承载场景的交互：
- Welcome 全段；
- Main/Idle 的全部视频与切换；
- Terry 召唤、展示、触碰、指向 UI 的全部镜头；
- Room 进入/返回过程中出现的视频交互；
- Ending 中若出现可交互对象的镜头；
- 后续新增的任何“视频 + 真交互 UI”画面。

**每一个交互镜头都必须独立通过同一验收标准。不能只把参考图对应的一瞬间做成毛绒 CG 融合效果，其余镜头降级为普通 DOM 浮层、贴纸按钮、静态 PNG 或与人物动作脱节的 UI。**

参考图定义的是：材质触感、世界一致性、空间关系、光影、遮挡、时序、物理反馈和“UI 像原本就在场景里”的质量标准。它**不是 UI 造型库，也不规定只能使用图中的对话框、铃铛、点赞等形状**。Codex 对每个交互场景拥有 UI art direction：应根据要表达的内容、人物动作、镜头空间和交互目的，自主设计最合适的交互对象、形态与动效；只要最终达到同等级的空间融合与视觉完成度即可。

# 不可妥协的 Main Space 视觉标准

## 1. 视频是世界本体

Main Space 应给人“进入 Terry 所在空间”的感觉。视频承担人物表演、场景、氛围和时间轴。页面不要呈现成普通网站背景视频 + 一层网页 UI。

`03_FINAL_VISUAL_TARGET.jpeg` 所表达的方向是：
- 柔软粉色毛绒空间；
- 写实人物；
- 克莱因蓝 / 柠檬黄 / 粉色等高饱和毛绒实体 UI；
- UI 有体积、有毛发、有柔软触感；
- 整体像同一个摄影/CG 世界。

## 2. UI 必须是真交互，同时看起来属于视频世界

按钮、入口和交互对象必须是真正可点击、可 hover、可 touch、可 focus 的网页对象。

但视觉上必须做到：
- 正确透视与尺度；
- 与镜头/人物位置对应的空间锚定；
- 合理 Z-depth；
- 场景一致的光照、环境色、软阴影/接触阴影；
- 合理景深和模糊；
- 与人物动作同步出现/消失/移动；
- 必要时被人物手臂、身体或前景物体正确遮挡；
- 点击/触碰时具有柔软实体反馈，例如轻微 squash/stretch、弹性阻尼、毛绒体积变化、位移或旋转反馈。

**禁止交付“视频上贴 HTML 卡片/PNG 图标”的方案。**

以下任何一种都视为失败：
- UI 像 HUD 或贴纸悬在屏幕上；
- UI 与镜头透视无关；
- 没有光影/遮挡；
- 用静态 UI 截图冒充可交互对象；
- 人物做动作而 UI 的时序和位置与人物动作脱节；
- 原透明水晶占位仍在下面穿帮。

# 视频 × UI 合成要求

现有 `welcome zone / mainline / ending` 视频中的透明玻璃/水晶对象是**位置、动作、运动和时序占位**，不属于最终材质。

Codex 应根据每个镜头选择合适方案：

1. **替换**：真实交互 UI 精确覆盖原占位，且不会穿帮。
2. **遮罩/分层**：为人物/前景建立 matte，让 UI 可以自然出现在人物前或人物后。
3. **预处理视频**：需要时用 FFmpeg、遮罩、修复/inpainting 或其他可用工具先移除占位，再在网页实时合成交互 UI。
4. **WebGL/Three.js 合成**：适合需要 3D 透视、材质、软阴影、空间运动的 UI。
5. **DOM 点击层**：即使视觉由 Canvas/WebGL 输出，也应保留可靠的可访问交互命中区。

技术栈不是验收标准，**最终看起来像 UI 原本就在这个空间里**才是验收标准。

如果某个镜头确实缺少做人像遮挡所需的 matte/depth/clean plate：
- 先尝试通过现有工具生成所需中间资产；
- 若仍不可可靠完成，明确记录缺少什么素材；
- 不得为了省事降级成明显贴纸式 UI。

# 开发方式

- 直接建立可运行网站，不把“先整理完所有资料”当作前置条件。
- 可以内部创建/维护 `MASTER_SPEC / SITE_MAP / INTERACTION_SPEC / CONTENT / ASSET_MANIFEST / DESIGN_SYSTEM / ACCEPTANCE_CRITERIA`，用于工程一致性。
- 可研究成熟开源页面/导航/动效架构，复用工程结构和交互机制；不要复制模板人格和视觉。
- 最终只选最有叙事价值的素材，不追求把所有图片、视频、项目塞进页面。
- 桌面与移动端都要可用；可根据设备调整构图和交互，但不能把核心沉浸感降级成普通卡片列表。
- 对性能做实际预算：视频预加载、编码格式、分辨率、自适应资源、lazy load、GPU/移动端降级都要处理。降级可以减少粒子/毛发计算，不能退回贴纸 UI。
