# 网站需求摘要

依据：网站构想、云盘入口索引、开发要求；摘要不替代原文。

## 定位

Terry 的多元个人数字空间，兼顾认识本人、经历与作品、小说、个人 AI 产品、收藏分享和当前业务。不压缩成单一职业标签。

标语：**All of this is me. / None of it is all of me.**

## 页面与动线

`Welcome → Main / Idle → Terry 展示入口 → 选择 Room → Transition → Room → Return → Main`

六个房间：About；Work / Resume / Cases；Novels；PTG；Terry Studio；Freeframe Studio。

每个房间有明显的大型 Return，语义为“回到 Terry 所在的地方”。Ending 由用户主动结束触发，避免依赖关闭浏览器播放。

## 视觉要求（来自文字，尚未查看图片）

全屏动态粉色空间，写实数字人 Terry，柔软毛绒立体 UI，克莱因蓝和柠檬黄为重要配色。各房间可采用成熟交互骨架并重新设计，保持全站材质、运动和反馈一致。

UI 必须有真实点击、触摸、悬停、键盘焦点和状态反馈；空间透视、尺度、光照、软阴影、遮挡、时间轴和人物动作需匹配。原视频水晶/玻璃为占位。不能把静态截图或贴纸式浮层当成最终交互。

素材缺少 matte/depth/clean plate 时记录真实缺口，不能假装已经完成。WebGL/Canvas/DOM/视频预处理均是候选方案，尚未选定。
