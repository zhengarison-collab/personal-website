# personal-website

这是 `zhengarison-collab` 的个人网站初版，使用原生 HTML、CSS 和 JavaScript 构建。

## 页面内容

- 首页：个人定位与简介
- 关于我：兴趣方向和技能
- 项目：展示 GitHub 项目
- 联系：GitHub 和邮箱入口

## 本地预览

直接打开 `index.html`，或使用 VS Code 的 Live Server 扩展预览。

## GitHub Pages

在仓库的 **Settings → Pages** 中选择：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`

保存后，网站通常会发布到：

`https://zhengarison-collab.github.io/personal-website/`
