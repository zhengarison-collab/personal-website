# 用户愿景构想（最高优先级）

> 后续 Agent 开始任何设计或开发前必须先读本文件。若本文件与较早的方案、文件名或素材说明冲突，以本文件为准。

我不想要那种一打开就满屏文字、菜单、卡片千篇一律的模版化网站，我更想把它做成一个让人记忆深刻的「个人空间」，有很强的额

用户第一次打开网站的时候，整个浏览器就是一块完整的画面。没有明显的网站边框，也不会感觉自己是在看一个网页，整个屏幕直接被视频占满。我准备的视频里目前呈现的交互方式是欢迎用户进来的写实化 AI 制作的呈现我本人形象的数字人交互视频。

开屏视频是数字人“我”在一个无边的米黄色空间里，我尚且把这个空间叫主空间，视频画面里 “我” 会召唤出来的 网页按钮 UI ，点击按钮后用户会进入到对应的主题空间里，目前主题空间有:【关于我】【工作经历+简历+过往案例】【我写的长篇小说:十余本】【我做的 app:PT.G】【我的佛牌小店 Terry studio 】 【我目前在做的事情 freeframe studio 】，以上这几个板块。

关于在这个主空间里，主空间永远会浮现出几个比较大的 UI 通往各个主题房间，因为我也想不到有什么比较好玩有趣一点的 UI 逻辑。

这些 UI 我想它们可能是玻璃、云朵、树脂、金属、石头、柔软材质，形状也不需要统一成方形或者圆形。例如:学历可以是一顶很干净立体毛绒学士帽，Work 可以是一个 Q 版写实的文件夹或者公文包，Brand 可以是一块有质感的石头或者金属标记，Projects、Novels、About、Contact 也都可以有自己的形态，但必须从材质交互触感上有很"哇塞！"的设计。

这些 UI 还需要比较大可以凸显视觉，也可以盖住视频里原有的 ui 占位符，请自行设计 UI 元素的摆放和大小一整套，可以五彩斑斓也可以统一色系，怎么好看或者有趣就怎么设计。

然后关于每一个主题房间，比如 Profile / About，里面可以是任何展现形式，这些房间也可可以去 GitHub 找已经做得很成熟的优秀开源页面结构，再根据我的内容重新设计，把空间包装成我自己的独特设计风格，无需让每一个板块都从零发明一种交互，这样太费算力了，直接找现成的开发好的但前提是必须保证视觉效果和交互体验感好的。

我只想到很简单的动线逻辑就是主空间指引进各个房间，然后房间回主空间，不管用户去了哪里，看完以后，都只能回到主空间，当然我开放欢迎一切新奇好玩有趣逻辑清晰明了的 UI 动线和交互方式，可以帮我出谋划策一下。

目前我能想到的就是每个房间下面都要有一个非常明显、非常大的 Return。它不是浏览器意义上的“上一页”，而是“回到 Terry 所在的地方”。

所以整个网站的路径永远是：

我 → 一个房间 → 我 → 另一个房间 → 我。

Welcome 和 Ending 我目前做出来的视频内容大概是我在见到客人来网站时，匆匆忙忙跑过来迎接，中间的视频就是百无聊赖等待的状态。当用户离开或者结束浏览，最后会是一个我跟大家挥手拜拜的画面，一个 ending 视频。

我目前还没想到这个网站的用途，我也不知道要贴什么标签，但确实我也不想给自己贴标签，我希望它是多元的，可以接纳一切的。之前有写过一些记录想法，你们也可以用来参考:

1: 用途：求职 / 接单 / 学术 / 自我介绍/认识我/仅仅只是发给别人看看/或许能有什么让别人对我感兴趣/或许给我更多机会/随手发不想解释太多

2 技术偏好：有点小心机但不要太明显地装个技术逼，就是让人看了感觉：哇！这人有点东西，有点审美，各方面能力审美都在线，但又很自然不炫技的就行。视觉上是这种感觉就行。

3 必须有的板块：

板块一：我的个人简介+简历（项目展示图文视频）

板块二：我写的 长篇小说展现（书名简介+书封面）

板块三：我做了一个 macOS 本地 AI App(也不知道要不要放，其实也没啥特别的，很多 app 都能做到。就是集 IMACopilot 的知识库功能和 gptcodex 的编程环境，接 API 即可可以处理大型文字内容文件和巨型编程项目，验证过完成的任务就是我一个对话发一个任务，读完我和 gpt 4000 多万字的全量聊天记录，把里面的内容根据我给的世界观设定改编成 60 万字的小说，它完成了，给其他 AI 看了成品小说全部评价 S+， 当然也有 PWA 版本，我会挂在 github 上给大家免费拉取使用）

板块四：我自己有一个佛牌小店，目前暂时不以盈利为目的，页面可以放我的店 logo 也可以用好玩的方式呈现和一些收藏的佛牌的画面，以及去做功德善事的画面，就一个交流分享的板块咯，有发烧友同行客户大家都可以一起交流互相学习的板块。

怎么说呢，我想看看 GitHub 有没有现成的站内浏览动线的设计可以直接搬过来，套个成熟的骨架，就不会“鬼打墙”点进去了出不来啥的。其余如何展示个人视觉风格的到时候就可以慢慢创作往里填也可以。当然风格也可以找找，反正我现在完全不知道往哪走，风格也没想好，骨架也不知道怎么挑选可以合理展示我的，我又不想太把自己贴标签，我希望它是自由又统一的，所以其实每个主题空间都可以设计成一个独立世界，可以很宏伟庞大也可以很小巧精致。反正做这网页我也不是专门用来求职或者完全当作品展示，所以我的首页现在的 slogan 还是：“All of this is me. / None of it is all of me.”反正我希望它多元一点，不要硬贴我就是做什么的这个标签。

以上便是我构想，想要的网站，你们也可以提出别的思路和解决方案。

反正我的诉求就是动效要多，要逼真清晰，那些 UI 设计一定要 CGI那样嵌入视频里才行，不能有违和感贴纸感，要发生在同一个空间。然后 ui 可以修改，原有的 UI 只是用来占位而已。

以上是我对我的网站的描述，如果有什么不足的你帮我把关，如果我没有提及的内容或者是我的疏漏没有说清明白的，你就按照当前热门，要么视觉效果最好，要么就是反正就是让整个网页让别的用户看用起来或者是看起来更加觉得我这个人有料牛逼的方式，你自己发挥帮我填充完整。
